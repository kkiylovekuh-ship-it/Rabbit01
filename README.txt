吉備路マラソン コースナビ（iPhone用 Webアプリ / PWA）
================================================

■ iPhoneで使うまで（初回だけ・約5分）
iPhoneのGPSはhttpsのサイトでしか使えないため、このフォルダを無料のWeb公開サービスに置きます。

【方法A：Netlify（ドラッグ&ドロップだけ）】
 1. パソコンで https://app.netlify.com/drop を開く（無料アカウント作成・ログイン）
 2. 解凍した「kibiji-app」フォルダをそのままドラッグ&ドロップ
 3. 表示された https://〜.netlify.app のURLをiPhoneのSafariで開く

【方法B：GitHub Pages】
 1. GitHubで新しいリポジトリを作り、フォルダの中身を全部アップロード
 2. Settings → Pages → Branch: main / root を選んで保存
 3. https://ユーザー名.github.io/リポジトリ名/ をiPhoneのSafariで開く

■ ホーム画面に追加
 Safariの共有ボタン →「ホーム画面に追加」。以後はアプリのように全画面で起動します。
 初回起動時に「位置情報の使用」を許可してください。

■ 大会前日までにやっておくこと
 ・設定 →「コース周辺の地図をオフライン保存」（Wi-Fiで。当日電波が混雑しても地図が出ます）
 ・設定 →「音声テスト」で音が出るか確認（マナーモードでも音声は出ますが、音量を上げておく）
 ・設定 →「シミュレーション走行」で動作を確認（終わったら「記録をリセット」）
 ・目標タイムを入力（ゴール予測と関門の余裕計算に使います）

■ 当日の使い方
 1. スタート地点でアプリを開き、スタートラインを越えたら「スタート」
 2. 画面は点けたままにしてください（iPhoneは画面ロックでGPSが止まります）
    → 設定アプリ「画面表示と明るさ → 自動ロック → なし」にしておくと確実です
 3. 1kmごとにラップ・経過時間・平均ペースを音声で案内
    給水所の約300m手前、関門通過時（閉鎖までの余裕）、中間点、ゴールも案内します
 4. コースから50m以上外れると赤い警告＋アラーム音＋音声でお知らせ
 5. ゴール（42.195km）で自動的に終了。「ラップ」画面で記録確認、GPXで保存できます

■ 注意
 ・コースは2026年10月公開の公式コースマップ（2027年2月28日開催）をもとに道路に沿って作った概略ルートです。
   公式の関門km（7.8/12.0/16.4/21.8/25.0/31.7/35.7/38.5km）に合わせて距離を補正していますが、
   数十〜数百m程度のズレはあり得ます。最終的には当日の大会案内・係員の指示に従ってください。
 ・関門閉鎖時刻・給水所の位置は「予定」です。
 ・コース外れ警告はGPS精度に左右されます（ビル陰・高架下などで誤警告の可能性あり）。
 ・地図：国土地理院 地理院タイル
